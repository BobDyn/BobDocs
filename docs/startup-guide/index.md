# Getting started

| Goal | Starting point |
| --- | --- |
| Vehicle setup, analysis, and reports | [BobSim installation](/startup-guide/bobsim) |
| A packaged desktop app | [Desktop and native Python](/startup-guide/bobsim-without-docker) |
| Modelica model development | [BobLib installation](/startup-guide/boblib) |

BobSim includes a pinned copy of BobLib. A separate BobLib clone is useful for
model development, but is not required to use BobSim.

[BobSim](/bobsim/) explains the available analyses. [BobLib](/boblib/) explains
the physical models and their public interfaces.
