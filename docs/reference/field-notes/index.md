# Engineering Knowledge Base

A reference of core definitions, governing equations, assumptions, and
engineering interpretation from coursework, projects, labs, and independent
work. Use it for orientation and recall, not as a substitute for full course
notes or dedicated references.

| Page | Covers |
| :-- | :-- |
| [Math And Modeling](/reference/field-notes/math-and-modeling) | Linear algebra, Taylor expansion, model structure, balance laws, scaling, and energy domains |
| [Mechanics And Materials](/reference/field-notes/mechanics-and-materials) | Frames and kinematics, momentum and energy methods, stress and fatigue, materials, and corrosion |
| [Signals And Controls](/reference/field-notes/signals-and-controls) | Laplace and Fourier transforms, sampling, PID, state feedback, LQR, and Lyapunov methods |
| [Thermal And Fluids](/reference/field-notes/thermal-and-fluids) | Conduction, convection, radiation, the first and second laws, and pipe and external flow |
| [Vehicles And Tires](/reference/field-notes/vehicles-and-tires) | Bicycle model, load transfer, handling metrics, slip, relaxation length, and tire fitting |
| [Data And Computation](/reference/field-notes/data-and-computation) | Probability, inference, regression, constrained optimization, and numerical solvers |
| [Embedded Systems And Software](/reference/field-notes/embedded-and-software) | Embedded control loops, sensors and data acquisition, engineering software, and networking |
| [Design And Manufacturing](/reference/field-notes/design-and-manufacturing) | Manufacturing, CAD geometry, requirements and trade studies, validation, and engineering economy |
